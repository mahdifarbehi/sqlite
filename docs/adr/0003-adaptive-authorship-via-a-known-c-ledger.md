# Adaptive authorship via a "C you know" ledger

The learner writes anything using a concept new to them — that's where the learning
is. The mentor may pre-write code made only of already-known constructs, to save
typing. The "C you know" list in `PROGRESS.md` decides which side a construct is on,
and grows over time.

Chosen over the extremes: mentor-writes-all (fast but passive) and
learner-writes-all (deep but brutal typing for a beginner).
