# Learn C first (briefly), then one thing at a time

The learner knows Python, not C or database internals. To avoid two hard things at
once: a short C foundation first (v0) — only what a database needs — then build the
database and pick up more C as it comes up.

Rejected: learning all of C first (boring, quit risk) and diving straight in
(drowning in pointers and new database ideas together).
